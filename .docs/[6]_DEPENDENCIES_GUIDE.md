## Packages Installés

next : Framework React avec App Router et optimisation d'images.
Raison : Stack standard du système Atelier.

react, react-dom : Bibliothèque d'interface et moteur de rendu.
Raison : Version 19 moderne compatible Next.js 15.

typescript : Typage statique strict.
Raison : Sécurité du code et maintenance à long terme.

tailwindcss : Framework CSS utilitaire.
Raison : Permet d'implémenter exactement la palette de marque émeraude et or sans css mort.

lucide-react : Bibliothèque d'icônes SVG optimisée.
Raison : Icônes légères, cohérentes et sans surcharge.

clsx, tailwind-merge : Utilitaires de fusion de classes conditionnelles.
Raison : Gestion propre des états actifs et dynamiques.

@next/swc-wasm-nodejs : Compilateur SWC WebAssembly pour Node.js.
Raison : Assure des builds stables et rapides dans l'environnement Termux / Android aarch64.
